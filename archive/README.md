# archive/

This folder keeps assets and code that are no longer part of the active
codebase but are worth preserving for future reference. Nothing in here
should be imported, required, or depended on by runtime code.

## Contents

### `scratch/`

Ad-hoc debug / one-off investigation scripts that are not part of the
application and were sitting at the repo root.

- `debug_tenants.js` — standalone mongoose script that dumps every
  Tenant document in the admin DB. Connects directly via `config/`
  rather than going through `utils/connectionManager.js`, so it's a
  debug helper, not production code.
- `report` — freeform text notes from a bug-fix session (order
  page / discount validation improvements). Kept for historical
  context.

### `test-outputs/`

Rendered HTML output from legacy template-engine test runs. These were
generated by `themes/*/demo.js` + `scripts/test-template-rendering.js`
and were committed to the repo root by accident.

- `test-output-elegance-jewelry.html`
- `test-output-tech-store.html`

### `design-references/`

Screenshots of a third-party reference storefront (Tonmart) collected
during theming/design research. Not used by any code.

- `tonmart-*.jpeg` / `tonmart-*.png`

## Follow-ups (done 2026-04-18)

A previous pass flagged the legacy Matjar template engine and its
demo themes as out-of-scope because a handful of runtime files still
imported from them. The 3D cleanup agent has since excised those
code paths, so the follow-up is complete:

- `template-engine/` — removed (done 2026-04-18).
- `themes/tech-store/`, `themes/elegance-jewelry/`,
  `themes/fashion-apparel/` — removed (done 2026-04-18).
- `middlewares/assetResolver.js` — removed (done 2026-04-18).
- `services/asset.js` — removed (done 2026-04-18).
- `utils/themeValidator.js` — removed (done 2026-04-18).

Storefront rendering is now fully served by the headless React themes
in `storefront-themes/`. No further archival work is required for the
legacy engine.
