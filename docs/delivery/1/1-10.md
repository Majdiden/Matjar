# [1-10] E-commerce Data Integration

[Back to task list](./tasks.md)

## Description

Integrate the template engine with the existing multitenant e-commerce platform's data models and repositories. This task ensures templates have proper access to shop, product, cart, customer, and order data while maintaining tenant isolation and following established data access patterns.

## Requirements

1. **E-commerce Data Context**:
   - Integrate with existing product, category, cart, order schemas
   - Support shop/store configuration and settings access
   - Provide customer and user data context for templates
   - Handle inventory, pricing, and promotional data

2. **Multitenant Data Access**:
   - Use existing repository patterns for data access
   - Integrate with current database connection resolver
   - Maintain tenant isolation throughout data access
   - Support tenant-specific schema variations and customizations

3. **Template Data Variables**:
   - Implement `shop` global variable with store settings
   - Provide `product`, `collection`, `cart` context objects
   - Support `customer`, `order`, `page` data variables
   - Add theme `settings` and configuration access

4. **Performance and Caching**:
   - Optimize data loading for template rendering
   - Support lazy loading of related data
   - Integrate with existing caching patterns
   - Handle high-volume concurrent data access

## Implementation Plan

   - Implement shop/store data context
   - Add product and collection data access

4. **Performance Optimization** (1.5 days):
