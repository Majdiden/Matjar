## Requirements

1. No page-level horizontal overflow (`document.scrollWidth`, `main.scrollWidth`) on any route at 360–430px.
2. Wide content (tables kept in table mode, code, JSON) scrolls inside its own container only.
3. Forms use single-column layouts on mobile with full-width primary actions; action rows wrap or stack.
4. Both LTR (en) and RTL (ar) verified.

## Implementation Plan

1. Audit script (scratchpad `audit/audit.mjs`): API login → seed localStorage → visit every route → measure overflow and list offending elements → screenshots.
2. Fix flagged pages/components; prefer shared fixes (DataTable, PageHeader, dialogs, tabs) over per-page hacks.
3. Re-run until clean in both languages.
