## Requirements

1. Layout: sidebar at `md+`; mobile sticky top bar with hamburger → slide-in drawer; bottom tab bar with ≥56px targets and safe-area padding; content padding `p-4 md:p-6`.
2. `DataList` primitive renders the table on `md+` and stacked cards below; every table page migrated (Tenants, Plans, Queues, tenant Orders/Payments/Exports/Failed webhooks, Phone countries).
3. Modals become bottom sheets on mobile (`max-h-[90dvh]`, scrollable body, stacked footer buttons). Toasts span the width on mobile.
4. Page headers stack; filter strips and tab strips scroll horizontally; long values wrap; JSON blocks scroll inside their container.
5. No horizontal page scroll at 360–430px.
