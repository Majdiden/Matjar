# [9-2] Merchant phone number with operator-managed country codes

[Back to task list](./tasks.md)

## Description

Capture the merchant's phone number at registration and let them edit it from their profile. The dial-code list is managed by the platform operator; Sudan (+249) is enabled and selected by default.

## Requirements

1. Storage: `phone` (E.164) + `phoneCountry` (ISO-3166 alpha-2) on `Tenant` (owner contact), `TenantUser` (directory) and the tenant-scoped `User`.
2. Normalisation (`utils/phone.js`): Arabic-Indic digits → ASCII; ignore spaces/dashes/parentheses; accept the same country's `+dial`/`00dial` prefix; strip one trunk `0`; enforce per-country digit bounds; reject foreign dial codes.
3. Registration accepts `phone` + `phoneCountry` (dashboard always sends both; optional at API for older callers), validates BEFORE the transaction and returns 400 on failure.
4. `GET /api/auth/phone-countries` (public) returns only enabled countries + default, never empty. `PUT /api/auth/me` updates name/phone and mirrors to directory + tenant (admins).
5. Operator config (`platformconfigs._id: "phoneCountries"`): `GET/PUT /api/platform/phone-countries`; validation of iso2/dialCode/digit bounds/duplicates; default must be enabled.
6. Dashboard: `PhoneInput` (native select + tel input, RTL-safe, offline-cached country list), phone on the signup account step, new Settings → Account tab.
7. Platform admin: "Phone countries" page (enable/disable, default, add from catalog or custom, remove), phone shown on tenant list/detail.
