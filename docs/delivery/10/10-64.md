# [10-64] Store websites open in Arabic by default

[Back to task list](./tasks.md)

## Description

Store websites open in the store's language (`settings.language`), but most stores had it set to English:
- **Signup** set it to the language of the dashboard during signup.
- **Settings** treated a store without a language as English, and saved "en" the first time the merchant saved General settings.

**What changes**
- **Signup:** every new store's language is Arabic, whatever language the merchant signed up in (`dashboard/src/pages/Register.tsx`).
- **Settings:** the settings page falls back to Arabic, as the server schema already does.
- **Migration 020:** existing stores move to Arabic. The previous value is kept in `settings.languageBeforeArabicDefault` for `down()`. Merchants who want English switch it in Settings → Regional.
