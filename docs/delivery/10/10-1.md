# [10-1] Charge Stripe in the store currency

[Back to task list](./tasks.md)

## Description

`createPaymentIntent` sent `order.totalAmount` (store base currency) to Stripe with `currency: order.currency || "usd"`. The order schema has no `currency` field, so every charge was in USD for the base-currency number. All Stripe amount conversions also hardcoded ×100 / ÷100.

## Requirements

1. Payment intents use `order.baseCurrency`, falling back to the tenant's `settings.currency` (default `SDG`, same as the storefront display).
2. If no currency can be determined, refuse to create the intent rather than default to USD.
3. Amounts convert to Stripe minor units per currency: ×1 for zero-decimal, ×1000 (rounded to a multiple of 10) for three-decimal, ×100 otherwise.
4. Partial refunds and captures scale by the payment intent's own currency, so intents created before this fix refund correctly.
5. Webhook amounts convert back using the event's currency.
