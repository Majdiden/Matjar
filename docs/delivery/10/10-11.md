# [10-11] Policies from questions + trust badges

[Back to task list](./tasks.md)

## Description

The merchant answers a few short questions about delivery and returns; we write the delivery, returns and payment policies for them using the delivery areas and payment methods the store already has. The same answers show short trust badges on product pages ("Cash on delivery", "Bankak transfer", "Delivery to: …", "Returns within 7 days"). Stores that never answer render exactly as before.

## Requirements

1. Questions: delivery areas (required only when the store has no shipping zones; zones are listed from `settings.shipping.zones` with their lowest price and estimate), delivery fee (optional, only without zones), delivery time (required); returns accepted (yes/no), within how many days (1–90, when yes), conditions (optional). Payment methods are read, not asked: enabled COD + manual-transfer providers with account details (only COD when the `payments.methods` flag is off — same as the storefront).
2. Output: `settings.policies.{delivery,returns,cod}.{title,body}` in the store's language (`settings.language`, Arabic default), from `POLICY_TEMPLATES`; answers escaped, bodies sanitised with the same rules as `controllers/settings.js`. Free-text answers fall back to Arabic in an English store. The payment policy (`cod` key) is written only when the store takes a payment method; an earlier generated, unedited payment policy is cleared when there is nothing left to say.
3. Answers stored additively at `settings.policyAnswers` = `{ deliveryAreas: {ar,en?}, delivery: {fee, time}, returns: {accepted, days, conditions}, language, generatedAt, generatedHash.{delivery,returns,cod} }`. `deliveryAreas` is shared with signup v2 (10-16) and prefills the first visit.
4. Edited protection: a policy whose stored body differs from `generatedHash` (or a hand-written policy with no hash) is "edited"; saving over it returns 409 `GENERATED_PAGE_EDITED` until `overwrite: true`.
5. Trust badges: storefront payload gains `trust` only once the questions were answered (`generatedAt`): `{ payments: true, delivery?: { zones?, areas?, time? }, returns?: { days } }`. `_shared/components/commerce/TrustBadges.tsx` renders nothing (and fetches nothing) without `store.trust`; payment badges come from the live `/storefront/payment-methods` (cached fetch shared with `GuaranteedCheckout`). Wired into `modern` and `starter` product pages under the guaranteed-checkout strip.

### API

```
GET /api/store-pages/policies         (settings.read | settings.write)
PUT /api/store-pages/policies         (settings.write)
body: { "answers": {
          "delivery": { "areas"?: {ar, en?}, "fee"?: {ar, en?}, "time": {ar, en?} },
          "returns":  { "accepted": boolean, "days"?: 1..90, "conditions"?: {ar, en?} } },
        "overwrite"?: true }

200 { success, data: {
  answers: {...same shape} | null, generatedAt, suggestions: { areas: {ar, en?} | null },
  language: "ar" | "en", currency,
  zones: [{ name, price | null, days | null }],
  payment: { cod: boolean, transfers: [{ code, label }] },
  policies: { delivery|returns|cod: { title, exists, edited } }
} }
400 bad answer · 401 · 403 · 409 { code: "GENERATED_PAGE_EDITED" }
```
