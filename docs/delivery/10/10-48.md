# [10-48] Storefront on phones: clear product photos, readable store name and logo, working contact details

[Back to task list](./tasks.md)

## Description

Feedback from a new store (Misk theme) on a phone:

- **Contact page** (`_shared/pages/Contact.tsx`, used by every theme): every value the merchant typed keeps its own direction (`dir="auto"`), so opening hours like «9ص-6م» no longer come out scrambled in an English page. The phone has "Call now" (and the store's WhatsApp when set), the email is a mail link and the address opens the map. The automatic contact page gets the same direction fix.
- **Product cards** (Misk and Linen, whose add-to-cart bar covered the photo on touch screens): each theme keeps its own card — heart, quick-view eye and the dark bar — and on touch screens the card is taller by the bar's height, so the photo shows as a full square and the bar sits below it. Desktop keeps the bar that slides up on hover.
- **Store name in the header** (all 18 themes): on phones it may take two lines at a slightly smaller size instead of being cut with "…"; one line on desktop.
- **Product names with numbers** (all themes, `_shared/utils/bidi.ts`): an Arabic name such as «1000جرام بخور عنبر ملكي» had its number thrown to the far side in an English page. Product, category and cart-line names that contain Arabic are wrapped in a first-strong isolate when they are localized, so they keep their own reading order everywhere they are shown (cards, product page, cart, search, wishlist) without changing each component. Latin names are untouched; the wishlist stores the plain name.
- **Checkout — detailed address** (`_shared/pages/Checkout.tsx`, all themes): the "Apartment, suite" line is now «العنوان بالتفصيل» / "Detailed address", a three-line box with an example (neighbourhood, street, nearest landmark, house). It is stored as the order's second address line, so it shows on the merchant's order page (relabelled to match), the receipt and the order emails.
- **Logo**: the phone logo slot is 44px (was 32–40px) in every theme. Logos drawn on a coloured square (a gold mark on purple) are now cut down around the mark at upload, keeping a band of the square's colour, so the mark fills the header slot. Existing logos: run `node scripts/trim-store-logos.js`.
