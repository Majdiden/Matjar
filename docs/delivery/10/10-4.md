## Requirements

1. `GET /api/store-profile` and `PUT /api/store-profile`, authenticated, same permissions as store settings (`settings.read`/`settings.write` read, `settings.write` write).
2. PUT is a partial update: only keys present change; `null` or `""` clears a field. A bilingual text is replaced as a whole (`{ ar }` alone drops a previous English text).
3. Accepted keys: `storeName` (2–100), `logo`, `brand.{tagline,coverImage,color,whatsapp,city,hours}` (+ input-only `brand.whatsappCountry`), `socialLinks.{facebook,instagram,tiktok,telegram,x}`, `contact.{email,phone,address}`. Unknown keys → 400.
4. Validation: colour `/^#[0-9a-f]{6}$/i`, stored lowercase; images `https://` or `/uploads/...` only; WhatsApp normalised to E.164 against the enabled phone countries (a pasted `wa.me` link or an international number is understood); social links through `utils/socialLinks.js`; bilingual text trimmed, capped, empty language dropped. Any invalid value → 400 with nothing written.
5. Each successful PUT writes a `settings.profile.updated` audit entry with the applied `$set`/`$unset`.
6. The response is the normalised profile.

### API

```
GET /api/store-profile
PUT /api/store-profile   body (all optional, at least one key):
{
  "storeName": "متجر النيل" | "" | null,
  "logo": "/uploads/..." | "https://..." | "" | null,
  "brand": {
    "tagline": { "ar": "...", "en": "..." } | "" | null,
    "city":    { "ar": "...", "en": "..." } | "" | null,
    "hours":   { "ar": "...", "en": "..." } | "" | null,
    "coverImage": "https://..." | "/uploads/..." | "" | null,
    "color": "#aa33cc" | "" | null,
    "whatsapp": "0912345678" | "+249912345678" | "https://wa.me/249..." | "" | null,
    "whatsappCountry": "SD"
  },
  "socialLinks": { "facebook": "facebook.com/x" | "" | null, ... },
  "contact": { "email": "...", "phone": "...", "address": "..." }
}

200 { "success": true, "data": {
  "storeName": string | null,
  "logo": string | null,
  "brand": { "tagline"?: {ar?, en?}, "coverImage"?, "color"?, "whatsapp"?, "city"?: {ar?, en?}, "hours"?: {ar?, en?} },
  "socialLinks": { "facebook"?: "https://...", ... },
  "contact": { "email": string | null, "phone": string | null, "address": string | null }
} }
400 validation / invalid value · 401 no token · 403 missing permission
```

## Implementation Plan

- `routes/storeProfile.js` (new), mounted at `/api/store-profile` in `routes/index.js`.
- `validators/storeProfile.validator.js` (new): zod shape + length, strict keys.
- `controllers/storeProfile.js` (new): thin handlers + `logAudit`.
- `services/storeProfile.js` (new): `buildStoreProfileUpdate` (validate everything, then build `$set`/`$unset`), `normalizeWhatsapp` (uses `resolveMerchantPhone`), `toStoreProfile`; reads/writes via `repositories/tenant.js` (`getATenantRepo`, `updateATenantRepo`). Single-document update is atomic, so no transaction.
