# [10-58] Regions: detect the visitor's region, let them change it, same prices from browsing to checkout

[Back to task list](./tasks.md)

## Description

A store selling in several regions (Settings → Markets: countries → currency, language, price adjustment) only applied the region at checkout, by shipping country. While browsing, visitors saw the website currency, and prices changed at the last step.

**Detect the region on arrival**
- `utils/visitorCountry.js` reads the visitor's country from CDN headers: `cf-ipcountry`, `x-vercel-ip-country`, `cloudfront-viewer-country`, `x-appengine-country` and `x-country-code`. Unknown placeholders are ignored.
- `buildStoreInfo` now carries `markets` (enabled regions whose currency is the pricing currency or has a rate) and `market`, the visitor's region or else the default one. This applies to both the embedded page payload and `/storefront/store-info`.
- The page sends `Vary` on those headers so a shared cache keys on the region.

**Region choice in the language menu**
- The menu offers "Region: Sudan (SDG) · Saudi (SAR) · Gulf (AED)" in place of the currency choice. The button shows e.g. "AR · SAR".
- The choice holds for the visit. Picking a region also switches the language to the one the merchant set for it; detection on arrival never changes the language.

**Same prices to checkout**
- `formatPrice` applies the region's currency and price adjustment everywhere, and the price filters convert back.
- Checkout renders the server quote's region numbers: prices and tax with the adjustment and rate, shipping with the rate only, and totals as quoted.
- Before an address is known, the quote uses the visitor's region (`marketCode`).
- When the delivery address belongs to another region, checkout says so: "Prices are for {region} ({currency}), where your delivery address is".

**Fix**
- The region total ignored discounts in `applyPresentment`, so a discounted order was overcharged in the region currency. The total is now goods-after-discount × adjustment + shipping + tax.
- `presentmentDiscount` and `presentmentPriceFactor` are added to the quote.
