# [10-22] Scroll to the field with a validation error

[Back to task list](./tasks.md)

## Description

Merchants on phones tapped Save and nothing seemed to happen when a field further up or down was wrong. Every client-side validation failure in the dashboard now scrolls that field to the middle of the screen and focuses it.

## Requirements

- `lib/focusFirstInvalid.ts`: `focusFirstInvalid(root?)` (first `[aria-invalid="true"]` / `[data-field-error]` after a frame), `focusFieldById(id)`, `focusField(el)`; `block: 'center'` keeps the field clear of the header and the mobile bottom bar; reduced motion respected.
- `ui/input`, `ui/textarea`, `ui/select` and `LinkSlugField` set `aria-invalid` when given an `error`.
- Inline-error forms call `focusFirstInvalid()` on a failed submit (product form incl. server field errors, content sections and variants; quick add; categories; About; Policies; signup steps).
- Toast-only forms focus the field the toast is about (collections, pages, menus, segments, companies, staff, invites, webhooks, redirects, order create, tax, markets, currencies, discounts, gift cards, payment methods, refunds, manual payments, notes/tags, roles, shipping zones, custom fields, domains, returns, replacements, fulfillments).
