# [10-60] Currencies tab without the Markets switch; currency/region choice in the phone menu

[Back to task list](./tasks.md)

## Description

**"You don't have permission" on the Currencies tab**
- The Currencies tab (and the product form's own prices) loaded its data from `GET /store-settings/markets`, which needs the `settings.markets` switch. With only Currencies turned on, it got 403.
- New `GET /store-settings/currencies` behind `settings.currencies` returns the same data. The Currencies tab and the product form use it.

**Currency switcher missing on phones**
- 15 themes (all but Atelier, Linen and Misk) use the shared phone menu (`_shared/components/navigation/MobileMenu.tsx`). That menu only had the English / العربية toggle, and those themes hide the header language menu on phones.
- The menu now shows a Region picker (stores with more than one region) or a Currency picker (switcher on), with the same note as the header menu. It uses a native select so the phone's own picker opens.
- Atelier, Linen and Misk already put the shared language menu, currency included, in their drawers.
