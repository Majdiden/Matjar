# [10-49] Storefront fixes from a live Misk store: recently viewed, descriptions, cart drawer, phone header, detailed address in orders

## Description

- **Recently viewed** (Misk): the rail showed every product as "Sold out" because it rendered the browser's saved snapshot, which has no stock. It now keeps only the ids and loads the products live (stock, price, name in the shopper's language).
- **Descriptions keep their reading order** (all themes): every product description, short description and collection description is rendered with `dir="auto"`; HTML descriptions also give each paragraph its own direction. «150جرام بخور شاف عالمي» no longer flips in the English storefront.
- **Cart drawer above the sticky add-to-cart bar** (all themes): the drawer (`_shared/components/CartDrawer.tsx`) now stacks above the product page's sticky bar, so its checkout button is never covered.
- **Misk phone header**: the logo at the start; wishlist and the menu button at the end (the menu drawer slides in from that side). Search and cart are in the phone's bottom bar; tablets, which have no bottom bar, keep them in the header.
- **Detailed address in the dashboard**: the order's address card labels «العنوان بالتفصيل» and keeps its line breaks; the edit dialog uses a multi-line box.
