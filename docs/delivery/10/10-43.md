# [10-43] Store logo in every theme header; names never clipped; larger footer logo

[Back to task list](./tasks.md)

## Description

Merchant feedback on a live store: the header showed only the store name, cut off at the bottom, and the footer logo was too small.

- **Header logo:** every theme's header (desktop and phone, sticky copies, the shared phone menu) shows the store logo beside the name — kept in proportion, rounded, on a white tile on dark headers; without a logo the header is as before.
- **Clipping:** the name was in a `truncate` box with a tight line height, so Arabic marks above and below the line were cut. The name is now its own single-line element with the font's own (or a roomier) line height and a little padding: long names end in "…" and are never cut top or bottom.
- **Footer logo:** 56–80 px (was 32–48), on a light tile where the footer is dark. atelier's filter that turned photo logos into a white block is gone.
