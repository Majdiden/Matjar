# [10-19] Natural-Arabic copy pass on merchant-facing screens

[Back to task list](./tasks.md)

## Description

Rewrite the Arabic strings on the merchant's main path (signup and sign-in, home, setup checklist, store pages, navigation, shared UI, products, orders) so they read as plain, natural Modern Standard Arabic: not dialect, not a word-for-word translation of the English, short and friendly for merchants with low tech literacy. Unify the word used for each concept across these screens.

## Requirements

1. Scope: Arabic files only, namespaces `auth`, `dashboard`, `onboarding`, `storePages`, `nav`, `common`, `products`, `orders` (`storeDesign` is out of scope; another task edits it). The English file is the meaning reference.
2. Follow the PRD copy guideline: plain, natural MSA; no dialect; written for meaning, not translated word for word; everyday words over jargon or transliterated English; brand/product names kept as before.
3. One word per concept across these files (glossary below).
4. Only stiff, literal, jargon-heavy, inconsistent or wrong strings change. No meaning added or removed.
5. Placeholders (`{{…}}`, `<1>…</1>`, `$t(...)`), plural suffixes (complete and grammatical for Arabic numbers), key names, structure and key order are preserved. Same JSON formatting (2-space indent, UTF-8, trailing newline).
