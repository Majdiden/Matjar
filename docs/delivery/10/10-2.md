# [10-2] Store language from signup, Arabic by default

[Back to task list](./tasks.md)

## Description

New stores always got `settings.language: "en"`, so a Sudanese merchant signing up in Arabic received English order emails, English default menus and payment-method names, and English starter content. A store now takes the language the merchant signed up in, and Arabic when none is sent.

## Requirements

1. `services/tenant.js` exports `DEFAULT_STORE_LANGUAGE = "ar"` and `STORE_LANGUAGES = ["ar", "en"]`, and uses the default when the request has no language.
2. Register validates `language` as `ar|en` (anything else → 400). Add-a-store passes only a supported value through.
3. The dashboard sends the current UI language on register and add-store.
4. Existing stores are unchanged (no migration).

## Out of scope (later tasks)

Storefront default locale and an Arabic fallback for missing English content (10-14).

## Test Plan
