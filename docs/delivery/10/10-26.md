# [10-26] Latin digits for prices, numbers and dates

[Back to task list](./tasks.md)

## Description

Since stores default to Arabic, prices and dates showed Arabic-Indic digits even in the English dashboard. Dashboard: `getTenantLocale()` = UI language + store region + `-u-nu-latn`, used everywhere numbers or dates are formatted. Storefront: `storefrontLocale()` for review, order and account dates.
