# [10-52] Status email templates: real default emails and translated status names

[Back to task list](./tasks.md)

## Description

Settings → Status templates showed a made-up placeholder with the internal status in English inside the Arabic text («طلبك {{orderNumber}} أصبح الآن pending.», «إلى حالة "Pending"»).

- The subject and message placeholders now show the email the store actually sends when the fields are left empty: the server's default for that status, in the dashboard language. A unit test keeps the two copies the same.
- The "Send this email" line names the status in the dashboard language («قيد الانتظار»).
- In emails, `{{status}}` is now the status in the email's language («قيد التجهيز», "being prepared") instead of `Processing`.
