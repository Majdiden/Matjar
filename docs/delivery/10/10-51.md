# [10-51] Live-store fixes: categories, notifications, short store links, store language, phone storefront

[Back to task list](./tasks.md)

## Description

**Signup and dashboard**
- Signup "What do you sell": categories added in the platform console showed a raw key (`auth.niche.<key>.tagline`) and an empty icon box. Only built-in categories show a tagline now. A category shows its picture, else its icon, else a tag.
- Platform console → Themes → Categories: an icon picker (30 icons, the same list the server accepts) and a picture upload (`POST /api/platform/storefront/theme-categories/:key/image`, audited). A PATCH can only remove the picture. Clearing an icon now reaches the server; before, the console's request helper dropped empty values.
- Notifications page: the kind ("New orders", «إعلانات من Matjar») and the severity are in the dashboard language instead of `platform.announcement` / `info`.
- Short store links: `GET /api/domains/suggest-subdomains?name=` builds short links from the store name and returns up to 5 that are free (rate limited like the availability check). Generic words are dropped («متجر», store, shop…), as are the «ال» / «لل» / «و» prefixes. The candidates are the first word, a spelling variant, the first two words, first word + store / sd, the initials, then numbered forms. «بيتنا أصل العطور السودانية» → bitna, betna, bitna-asl… At signup the link fills with the best one and the others are buttons. The dashboard's change-link dialog shows the same buttons.

**Storefront (all themes)**
- The storefront opens in the store's language (Settings → Regional); a store without one opens in Arabic. The shopper's switcher choice, or a link ending in `?lang=en` / `?lang=ar`, holds for that visit only. The store payload carries `language`, and the tenant schema default is now Arabic.
- Adding to cart blanked the page in Modern. In the shared toast, the loop variable `t` hid the translation function, so the first toast in any theme crashed the page.
- iPhone zoom on field focus: every text field is at least 16px on touch screens and phone widths (shared stylesheet loaded by `mountTheme`). Pinch-zoom still works.
- The product compare bar and the toasts sit above the floating bottom menu on phones (`--mbn-space`).
- Checkout:
  - On phones the stepper names only the current step, so it fits.
  - The first item's quantity badge is no longer clipped by the scrolling list.
  - Empty «العنوان بالتفصيل» boxes follow the page direction, so the Arabic placeholder is on the right. The same fix applies to the account address form.
  - The delivery-area list follows the page direction.
- Misk:
  - The menu opens from the reading-start side (left in English, right in Arabic).
  - The search placeholder is generic.
- Misk and Linen no longer show made-up "most searched" terms; only the merchant's own list shows.
