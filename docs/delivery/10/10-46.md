# [10-46] Platform notifications to every store or one store (app + phone/desktop + email)

[Back to task list](./tasks.md)

## Description

The platform team can send a message to all stores or to one store from the platform console ("Notify stores", scope `announcements.send`: owner, admin, operations).

- **Write once, two languages**: title and message in English and Arabic. Each store reads its own language (falling back to the other one). An optional dashboard link opens a page in the merchant dashboard; links outside `/dashboard` are refused.
- **Channels** picked by the sender, then filtered by each staff member's own switches for "Announcements from Matjar" in Settings → Notifications:
  - **App notification**: through the same pipeline as a new order (`services/notification.js#emit`): the notifications page and bell, the live popup in an open dashboard, and a phone / desktop notification (Web Push) when the dashboard is closed.
  - **Email**: a formatted message (`services/emailTemplates/platformAnnouncement.js`) in the store's language, with a button into the dashboard and a link to the notification settings. On by default for this type; staff can switch it off.
- **Before sending**, the page shows the reach of each channel: people, phones / computers with notifications on, inboxes, and whether push and email are set up on the server.
- **History**: the last 50 messages with target, channels, reach, delivered counts and status. Delivery runs in the background and the page follows it.
- Also fixed on the way: Web Push now honours each person's "phone and desktop" switch for every notification type, and the live popup is shown in the dashboard language (it used to show the stored English text).
