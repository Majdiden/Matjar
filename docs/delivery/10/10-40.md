# [10-40] Store-centred link preview card

[Back to task list](./tasks.md)

## Description

A shared store link showed a white 1200×630 card with the logo small in the middle; WhatsApp (the main sales channel) shows wide images as a thin strip, so the store hardly showed. The share card (`services/ogCard.js`, `GET /og/store-card.png`) is now a square 1200×1200 card about the store: the cover photo (darkened towards the bottom) or the store colour with a soft glow; the logo large on a white rounded tile — a photo logo fills the tile, a wordmark or transparent logo sits whole inside it, no logo shows the initial; the store name, its short line and the store link. Arabic text is rendered with the bundled IBM Plex Sans Arabic font through Pango, so it does not depend on server fonts. The page tags declare the new size and add a version to the image URL (`?v=`) that changes with the name, logo, colour, cover or short line, so apps that cache previews by URL refresh them.
