# [10-30] My store fixes: store info, contact details, About follows the name

[Back to task list](./tasks.md)

## Description

Feedback from the test store:

- In the English dashboard every bilingual field read right to left. `BilingualField` now shows the English input first, left to right, when the dashboard is in English; Arabic stays first in Arabic.
- The site identity page had no Save button. It still saves each field as it changes, and now ends with a Save button that sends anything pending, waits for it and says whether it worked (scrolling to the first wrong field otherwise).
- The Contact page read phone, email and address from `settings.contact`, which nothing in My store filled. Site identity now has a "How customers reach you" card for them, suggesting the account's phone and email.
- The generated About page kept the old store name after a rename. Renaming the store (store profile or settings) rewrites the generated About page from its saved answers, unless the merchant edited it by hand.
- The guided setup opened only the first step automatically. It now opens each new current step once per session.
