# [10-35] Platform admin quick search (Ctrl/Cmd+K)

## Description

The platform owner asked for search in the platform admin to navigate quickly. A quick navigator opens from the top-bar search button (on every screen size) or with Ctrl/Cmd+K (or "/"), and finds pages, page tabs and stores.

## Requirements

1. Opens with Ctrl/Cmd+K and from a search button in the top bar (visible on phones). Up/Down, Enter, Esc; mouse and touch select; focus trapped while open and restored on close; dialog/combobox/listbox ARIA.
2. Pages: every page and deep-linkable tab, derived from `components/nav.ts` and filtered with the same scope checks as the sidebar and tab strips.
3. Stores: search by name, owner email, slug, subdomain host or custom domain through the existing `GET /api/platform/tenants?q=` (support.read, regex-escaped, 100-char cap, list projection only), 8 results, link to all matches; selecting opens the store page.
4. Debounced (250 ms), stale requests aborted, loading/empty/error states.
5. Recent: last 6 opened results in localStorage, keyed per operator; entries the operator can no longer open are hidden.

## Implementation Plan

- `components/nav.ts`: `NavTab`, `BILLING_TABS`, `TENANT_TABS` (with per-tab scopes), `canSeeTab`, `tabHref`; Billing and TenantDetail render their tab strips from these lists.
- `lib/commandPalette.ts` (new): page index, matching, recents, shortcut hook. `components/CommandPalette.tsx` (new): the dialog. `components/Layout.tsx`: top bar on all sizes with the search button.
- Backend: `listTenants` search also matches `domains.subdomain.name`, `domains.subdomain.fullDomain`, `domains.customDomain.name`; per-operator rate limit on searches (120/min, requests without `q` are not counted).
